# Cloud Concepts Reflection

Cloud services have become an important part of my everyday life because they allow me to access applications, files, and information from different devices. Three cloud services that I regularly use are Google Drive, Canva, and Messenger.
Google Drive is an example of Software as a Service because I use it through a web or mobile application without managing the underlying servers or infrastructure. It uses a Public deployment model because Google provides the service to users through the public cloud.
Canva is also SaaS because I access its design tools through an application without having to install or manage the cloud infrastructure behind it. It can also be classified as a Public cloud service because it is offered to many users over the internet.
Messenger is another example of SaaS because users access its messaging features through an application while the provider manages the servers and other infrastructure. It uses a Public deployment model because the service is available to users through the internet.
Git and GitHub are important when working with cloud infrastructure because cloud projects often involve many files, configurations, scripts, and changes made by different team members. Version control allows developers to track changes and identify who made specific modifications.
It also provides a history of previous versions, making it easier to restore files when errors occur.
GitHub helps teams collaborate by providing a shared repository where members can upload, review, and manage project files. Features such as commits, branches, and pull requests help teams work on different parts of a project without accidentally overwriting each other's work.
This is especially useful for cloud infrastructure because a small configuration error can affect an application or service. Overall, Git and GitHub make cloud projects more organized, collaborative, and reliable.
